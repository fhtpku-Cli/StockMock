# 0.3.0 独立集成验证

日期：2026-10-23。结论：本轨道 Q01、Q02、Q04–Q09 与 Q11 的接口、兼容及交易行为通过。实际执行195次 `curl -i` 请求，22项行为场景、11项对抗场景；完整矩阵位于忽略目录 `.omo/evidence/0.3.0/integration/0.3.0-manual-qa.md`，机器可读版本为同目录 `manual-qa.json`。本记录不替代 Q03/Q10 浏览器交互、Q12 正式部署及最新提交CI，不代表真实外部行情、iPhone或整机重启验收。

## 隔离范围

全部服务只监听 `127.0.0.1:8337`，独立临时SQLite、认证会话和受控行情/时间；实际应用API、SQLite事务、交易引擎和生命周期后台均为候选代码。没有调用正式端口8000，没有读取或修改正式数据库，没有正式测试单。旧库验证输入仅为PM事先在线备份的私有一致副本，再复制到本轨道目录操作。原私有域名和密码没有读取、记录或输出。

本轨道不修改产品代码。所有服务均记录PID与端口，在脚本 `finally` 中结束；5份 `*-resource.json` 均确认 `stopped=true`、`port_closed=true`。隔离Cookie已删除，受控库和HTTP证据保留在忽略目录。旧库副本含个人记录，仅供本机核验，不提交公开仓库。

## 复跑与证据

在当前项目根目录顺序执行，勿并行占用8337：

```sh
PYTHONPATH=backend backend/.venv/bin/python work/0.3.0/qa_compatibility.py
PYTHONPATH=backend backend/.venv/bin/python work/0.3.0/qa_http.py
PYTHONPATH=backend backend/.venv/bin/python work/0.3.0/qa_analysis.py
PYTHONPATH=backend backend/.venv/bin/python work/0.3.0/qa_edges.py
PYTHONPATH=backend backend/.venv/bin/python work/0.3.0/qa_report.py
```

`qa_server.py` 为只存在于 `work/` 的夹具入口，包含显式受控行情、时钟和造数端点，不注册到正式应用。每次请求执行前记录调用，HTTP状态、响应头和正文存于各 `*.http` 及 `*-http-transcript.txt`；认证Cookie已隐藏。各 `*-observations.json` 记录金额、边界和不变性断言，实际导出文件为 `filtered-ledger.csv` 与 `snapshot-range.csv`。`compatibility.json` 仅输出旧库逐表计数与相等性，不公开个人内容。

夹具校准中确认了既有保护：非法手数实际为422；跨日后会话按期过期需重新登录；同一时刻取消预挂单即时撤销；拆股当日参考价保护阻止继续下单。调整测试输入后完整重跑通过，未修改产品逻辑，也未把这些保护误报为产品缺陷。

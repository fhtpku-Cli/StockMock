# 前端验证记录

验证日期：2026-10-22。项目目录：StockMock。结果为可供独立评审的本地候选版，不代表真实手机、外网部署或实时成交已验收。证据在私有目录 `.omo/evidence/frontend/`，本报告中的路径均相对项目根目录。

## 已实现范围

浅色资产看板、自选与按名称/代码搜索、市场筛选、证券报价与历史图、限价默认及带 2% 保护的市价模拟表单、预览确认、撤单、关联复盘、CSV 导出、现金与换汇、私有登录、归档重开和只读历史查看。页面显示资金币种、行情来源与北京时间、占用及等待状态。港美股未核验时只观察；四个 A 股样本按后端清单允许模拟交易。

初始本金由真实服务返回 1,000,000 CNY；无持仓时展示空状态。没有静态持仓、假收益或外部行情失败后替换假数据。资产历史快照接口尚无，资产轨迹区明确说明缺失，不绘制假曲线。归档界面不含买卖或修改历史操作；按最早轮次为 1 编号。

## 已发现并修复

预览端口 4173 的写请求被后端跨站保护拒绝，现默认在同源 8000 或被允许的 5173 上运行，未放松安全限制。手机青色说明区两处文字对比不足，调整为更深的青色后四页 axe 违规归零。证券价格最初复用两位金额格式，已改为按 tick_size 的独立价格格式并用真实 ETF 复验。原生弹窗增加可访问名称；表单按钮显式区分提交与普通操作。

截图曾在弹层淡入途中捕获透明重叠，最后一轮截图禁用截图期间的动画推进并重新捕获，实际交互仍保留 160ms 动效与减少动态效果支持。全部 TS/TSX/CSS 和测试脚本已格式化；登录、侧栏与样式按责任拆分，没有压成单行的源码。

## 代码自查与边界

API 结果在 Zod 边界解析；没有 `any`、非空断言或错误吞掉。交易更改字段时生成新 request_id；同一表单失败重试保留原编号；提交按钮在请求期间禁用。金额仅展示格式化，账本计算留在后端。使用同源 Cookie，不在前端存储密码或令牌。生产包未加载开发专用的 react-grab/react-scan。

React Doctor 无错误，仍有 App/Detail/Journal/Trade 的控制流复杂度提示和侧栏同时导出导航常量的 Fast Refresh 提示，属于后续可维护性优化，不作为功能通过证据。没有执行 Lighthouse 全类目满分或真实 React 渲染提交追踪，不宣称这两项通过。

当前尚未用浏览器验证真实盘中成交后的持仓展示、实际卖出成功及有外币余额时成功换回人民币；成交账本的独立后端测试由后端报告覆盖，不能等同于这些浏览器路径。真实设备安装、iOS Safari、手机外网访问、大陆实际网络、常驻托管均未完成验证。只提供浅色主题。归档每类最多展示最近 500 条，界面提示截断，完整流水可单独导出。

## 用户集中体验步骤

1. 按 `frontend/README.md` 启动，打开 `http://127.0.0.1:8000`，用自己设置的密码登录。
2. 在资产页核对资金、占用及持仓；进入自选搜索熟悉标的，添加或移除星标。
3. 打开 A 股样本，核对来源和报价时间；填写限价与理由，先看预览，再决定提交。港美股当前只观察。
4. 在委托页查看状态；申请撤单后，以“已撤单”回执为准，不能把点击申请当成已经释放资金。
5. 写一条复盘，刷新后查看；导出 CSV。需要重开时，先结束进行中的委托，再到设置输入确认文字。
6. 在设置打开旧轮次，确认旧笔记与委托仍可只读查看。手机实际设备和外网访问由后续集中验收安排。

本地候选版可以进入独立评审；公开部署与真实成交体验尚不能据此宣布通过。

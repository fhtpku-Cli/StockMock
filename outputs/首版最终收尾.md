# 首版最终收尾

历史批次日期：2026-10-23；该批部署版本为`0.1.1`，不是当前正式版本。当前0.4.7完整交付见[0.4.7执行与验收记录](0.4.7执行与验收记录.md)。本批仅处理整体复核发现的三项遗留；用户已授权子智能体实现、验证、更新文档及版本。随后用户确认 iPhone 实机四项通过；Mac 整机重启验收继续后置，港股继续仅观察。

## 范围与分工

| 项目 | 预期结果 | 实施责任 |
| --- | --- | --- |
| 下单预览换汇信息 | 仅在买入实际需要人民币换汇且有有效参考时显示汇率、来源与市场时间；卖出、已有足额外币及人民币交易不显示内部默认值；不改变记账 | `closeout_backend`：后端和后端版本；`closeout_ui`：预览及界面测试 |
| 历史轮次复盘 | 归档委托可查看原计划、成交与确认时间、费用、来源、换汇依据及收益；关联笔记可展开原委托；保持只读及旧字段缺失说明 | `closeout_ui`：复用现有委托与复盘显示逻辑 |
| 日成交量 | 行情详情按市场日期展示已有日线成交量，日期选择与数值对应，零值和空数据明确处理 | `closeout_volume`：详情及成交量组件与测试 |

成交量沿用行情模型的来源单位，不推断为股或份，也不统一乘以 100；明确来源并提示不同市场或来源不能直接比较。此项用于观察同一标的的日成交量变化，不增加逐笔行情、盘口或成交量驱动撮合。

归档本批补齐已有订单与笔记的界面，不新增历史持仓估值、全量分页或复杂收益统计。所有成交与换汇验证使用临时账本，正式账户只做读取与部署保留核对。

## 验证与交付依据

1. 后端在临时 SQLite 或实际 HTTP 上验证正常换汇、卖出、已有足额外币且汇率不可用，以及缺额但无有效汇率的拒绝行为；预览不产生委托或流水。
2. 浏览器在下单确认页核对汇率，不以成交后的详情代替；归档后展开委托与关联笔记，核对旧记录空值、只读及手机尺寸布局。
3. 成交量核对日期、零值、大数、空数据及窄屏；真实行情只读验证与受控数据测试分别记录。
4. 主智能体执行集成浏览器验证、检查最终差异，核对版本、类型、相关测试与构建。验证记录放在被 Git 排除的 `.omo/evidence/final-closeout-20261023/`，公开文档只写脱敏结论。
5. 本机部署前在线备份，更新后核对原账户、后台运行、登录与只读页面；提交推送并核对对应提交的 CI。没有通过的项目不标记完成。

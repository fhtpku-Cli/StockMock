# 个人访问与后台常驻方案

更新时间：2026-10-22。后台工具已实际安装，首次启动被 macOS 文稿文件夹权限阻塞，现已停止待授权的服务并恢复原本的本机前台运行方式。Tailscale 私有入口等待本人启用 Serve/HTTPS。两项均未标为真实运行验收通过。

## 选择

沿用已有 Mac 与 Tailscale 账户，通过私人网络连接电脑和手机。应用继续只监听 `127.0.0.1`，由 Tailscale Serve 提供个人 HTTPS 入口，不启用公网 Funnel，不开放路由器端口，不更改其他应用的网络配置。主机已有可用 Tailscale 登录和 iPhone 设备记录，HTTPS 证书功能尚待开启；设备记录不能证明手机当前在线或已完成真机访问。

后台使用 macOS 当前用户的 LaunchAgent，在登录后启动单个后端进程、异常退出后恢复。密码由项目本地受限文件读取，不写入 LaunchAgent 参数或公开文档。账户数据库保持原位置，日志和运行配置留在被 Git 排除的本地目录。支持查看状态、停止、启动和卸载本项目的服务。

## 可持续运行的边界

关闭网页和终端后，用户级后台进程应继续处理。注销 macOS 用户、关机和主动休眠会中断服务，不能承诺等同云服务器的全天可用。当前主机接电状态已设置为不自动休眠，无需改变全局电源设置。网络恢复后遵循原有订单截止规则，不能补造停机期间成交。

若未来需要关机后仍继续处理，应把同一个应用部署到常开主机；本批不购买托管服务或开通账号。

## 验收步骤

1. 新旧数据库可读取；单实例启动，不产生两个后台 Worker 同时写账本。
2. 用户级服务启动后通过登录与健康接口读取实际运行状态；正常停止后端进程，观察服务重新拉起并保留原数据库。
3. 不发 HTTP 请求时，由后台独立完成受控行情下的订单处理，记录市场时间和确认时间。
4. HTTPS 入口拒绝未登录的账户读取；同源登录、写入、退出正确，跨站写入、非法 Host 被拒绝。
5. 手机使用同一 Tailscale 账户打开私有网址，登录后与电脑看见同一轮次；添加到主屏幕后再次打开。真机步骤必须实际完成才能标为通过。
6. 停止或卸载仅影响本项目服务和代理入口，不删除账户数据库、不重置其他 Tailscale 配置。

## 官方依据

- [Tailscale Serve 命令](https://tailscale.com/docs/reference/tailscale-cli/serve)：可将本地 HTTP 服务代理为 Tailnet 内的 HTTPS 服务，`--bg` 可在后台保存配置。
- [Apple 用户级后台进程说明](https://developer.apple.com/library/archive/documentation/MacOSX/Conceptual/BPSystemStartup/Chapters/CreatingLaunchdJobs.html)：LaunchAgent 跟随已登录用户，注销会停止，不能当作系统级常驻服务。

## 当前用户后台工具实现

工具位于 `scripts/service.py` 与 `scripts/run-service.py`。只使用当前项目现有 `backend/.venv/bin/python`，不在登录或启动时安装依赖；保持单进程、`127.0.0.1:8000`，端口冲突时拒绝启动，不终止任何现有进程。服务为当前 macOS 用户的 LaunchAgent，登录后启动，异常退出后重启；退出登录、电脑关机或休眠不承诺继续撮合。

使用项目根目录执行以下步骤：

```bash
backend/.venv/bin/python scripts/service.py install --dry-run
backend/.venv/bin/python scripts/service.py install
backend/.venv/bin/python scripts/service.py status
backend/.venv/bin/python scripts/service.py stop
backend/.venv/bin/python scripts/service.py start
backend/.venv/bin/python scripts/service.py uninstall
```

首次安装前需完成前端构建与后端依赖准备，并正常停止旧前台实例。`install` 会检查已有运行文件和配置；`uninstall` 仅卸载本工具当前用户服务，保留个人数据库、密码、日志和源码。没有 sudo 或全局网络配置操作。本轮 PM 已在 SQLite 在线备份后停止旧实例并实际执行安装；系统授权阻塞与后续操作见下方。

密码从 `backend/.local-password` 在进程内读取，不写入 plist、启动参数或服务环境变量。密码及可选配置文件必须由当前用户拥有，权限为 `0600`，拒绝符号链接。可选 `backend/.runtime.json` 是私密 JSON，不是可执行 shell 文件；仅允许字符串字段 `PAPER_ALLOWED_HOSTS`、`PAPER_ALLOWED_ORIGINS`、`PAPER_SECURE_COOKIE`、`PAPER_PAUSED_SYMBOLS`，以及行情接入使用的 `STOCKMOCK_INSTRUMENTS_FILE`、`STOCKMOCK_FUTU_PORT`、`STOCKMOCK_FUTU_BAR_LABEL`。精确可信主机与 HTTPS 来源仍由后端校验，不接受通配符。该文件不得提交，设置后停止再启动服务使其生效。

运行日志位于 `backend/data/logs/service.log`，每份约 1 MB，保留三份轮转；不记录访问请求，不输出密码。状态命令区分服务是否安装、加载与端口是否可连接，端口可连接不等于行情健康。界面资产页显示后台最近处理与估值状态。私有手机地址及 Tailscale HTTPS 激活仍由 PM 配置确认；本工具不创建或覆盖 Tailscale Serve 路由，不启用 Funnel。

隔离验证命令：`backend/.venv/bin/python scripts/test_service.py`。共 7 项测试，覆盖日志约 1 MB 轮转与三份保留、同名外部项目服务不能被卸载、plist 的 `plutil` 校验、含中文/空格路径、拒绝非白名单配置和非 0600 文件、端口冲突不启动也不杀进程、卸载保留数据库与密码、dry-run 不调用 launchctl。证据：`.omo/evidence/frontend-personal/service-tests.log`。

## 真实安装记录与本人操作

PM 使用 SQLite 在线备份保存了原账户，核对旧进程命令和项目目录后正常终止，再执行 `service.py install`。LaunchAgent 成功加载，进程存在，但 8000 端口未开放。进程采样停在 Python 初始化读取路径；macOS `tccd` 日志明确显示 `kTCCServiceSystemPolicyDocumentsFolder` 授权提示，尚未进入应用业务代码。此结果属于系统授权阻塞，不是已验证常驻。

本人需要在 Mac 的“Python 想要访问文稿文件夹”提示中选择“允许”。当前电脑工具拒绝操作该系统权限应用；没有修改 TCC 数据库、扩大完全磁盘访问或移动代码绕过授权。允许后，由开发方复验服务端口、原轮次、后台心跳，再正常终止服务 PID 验证系统重新拉起与账户持久化。若未看到提示，可打开“系统设置 → 隐私与安全性 → 文件与文件夹”检查 Python 的文稿访问；不要授予无关应用权限。

手机路径已生成 Tailscale Serve 启用页，并在任务浏览器保留。本人登录现有 Tailscale 账号，按页面启用 Serve/HTTPS；登录页含条款确认，不能替本人完成。配置目标为私有网络 HTTPS 的 8443 端口代理到 `127.0.0.1:8000`，没有启用公网 Funnel。私有主机名、账号与运行白名单只保留在被忽略的本地配置，不写入公有仓库。

启用并由开发验证代理后，手机操作：

1. 打开 iPhone 已有 Tailscale，登录与 Mac 相同账号并连接。
2. Safari 打开开发方返回的私人 HTTPS 地址，输入 StockMock 本地密码。
3. 核对与电脑相同的轮次、可用资金和委托；手机退出页面后再次打开，查看后台状态。
4. Safari 分享菜单选择“添加到主屏幕”，从图标再次进入并验证登录与页面。

真实 iPhone 登录与安装在本人完成之前一直保持待验证。端口、服务 PID 和私人网址不作为公有源码配置硬编码。

为保持现有网页可用，PM 在等待授权期间停止了未就绪的 LaunchAgent，并用相同项目启动器恢复本机前台实例。实际浏览器已重新登录，原轮次、本金、目录和后台心跳均可读。当前状态是“已安装、未加载、前台服务可用”，不是常驻已通过。下一次切换时先正常停止此实例，再执行 `service.py start` 触发或复用本人权限，不应同时运行两个实例。数据库在线备份保留在私有 `work/backups/`。

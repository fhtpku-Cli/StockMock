# StockMock 后端验证记录

更新日期：2026-10-22。以下路径均相对于 StockMock 仓库根目录。本报告描述本地个人候选版，不代表公开服务、券商成交或大陆网络已经验收。

## 已交付行为

Python 3.12、FastAPI 和 SQLite 单实例运行。每个新练习轮次以 1,000,000.00 元人民币、零外币和零持仓开始。金额用 Decimal 与分级舍入计算；SQLite 写事务和请求编号唯一约束保证受理、资金、份额、换汇、费用、成交记录一起提交。两个设备不能分别使用同一笔已占用资金。关闭网页不停止后端任务；关闭运行脚本或电脑休眠则不保证后台继续。

支持限价单、带 2% 边界的市价模拟、买卖各 0.05% 费用、整笔成交、当日有效、延迟撤单与到期。订单只使用下单之后的完整、正成交量分钟区间；市场时间、来源、币种、有效交易时段与截止边界均单独判断。不使用估值快照或日线高低点猜测成交；报价失败不会替换成演示数据。撤单等待期间继续占用资金；超出截止后 20 分钟仍无有效确认则以“数据不足，未确认成交”终止，不回填迟到样本。

已接入的四只境内证券可用完整五分钟样本模拟交易：`600519.SS`、`510300.SS`、`000001.SZ`、`159915.SZ`。港美股四只代表标的目前仅供观察，跨币种引擎通过受控测试，但不声称港美股真实成交链路已开放。普通股票、沪深 300 ETF 的 10% 与创业板 ETF 的 20% 日价格边界采用当前支持清单参数；不存在盘口时不在买入涨停、卖出跌停边界假定可成交。

A 股及当前两只境内 ETF 按成交所属交易日，到下一交易日开盘才可卖。订单预留既有外币，缺额按本单已保存的参考汇率预留人民币，实际成交才换汇；卖出净款保留外币。同币种余额足够时，汇率故障不阻止相应交易。外币换回人民币、复盘笔记、CSV 导出均有真实接口。

重开练习须先结束全部活动订单。旧轮次不删除；`GET /api/rounds/{id}` 可只读查看现金、订单、笔记及流水，每类最多显示最近 500 条并返回 `truncated`。`GET /api/rounds/{id}/export.csv` 导出该轮完整流水。归档轮次没有写入接口。

## 私有访问与启动

所有账户、行情及交易接口要求登录，启动未配置至少 12 字符的个人密码时不能登录。会话使用 HttpOnly、SameSite=Strict Cookie，最长十二小时；退出或重启后失效。写操作校验来源，登录失败有限速。本地默认只监听 `127.0.0.1:8000`，使用一个 worker，数据库固定为 `backend/data/paper.sqlite3`。公开源码不等于公开账户服务。

首次在项目目录运行：

```bash
cd frontend
bun install --frozen-lockfile
bun run build
cd ..
./scripts/start-local.sh
```

脚本读取已有的私有 `backend/.local-password`，没有文件时在终端隐藏输入并二次确认密码。若本机已有开发验证密码，停止旧服务后执行 `./scripts/start-local.sh --set-password`，设置自己的密码；无需删除数据库。浏览器打开 `http://127.0.0.1:8000`。`Ctrl-C` 停止服务。开发密码、数据库与原始行情样本不得提交公有仓库。

发现分红、拆股、风险警示或交易规则变更后，应先停止服务，以 `PAPER_PAUSED_SYMBOLS=600519.SS,510300.SS ./scripts/start-local.sh` 暂停涉及标的，再核对记录。暂停标的不受理新单，也不处理既有订单成交；仍按截止与超时规则释放占用。这是人工暂停能力，不是自动公司行动识别或自动账本修正。

## 本地行为验证

在 `backend/` 目录执行：

```bash
uv sync --frozen
uv run python -m pytest -v --junitxml=../.omo/evidence/backend/junit.xml
uv run basedpyright
uv run ruff check app tests typings
uv run ruff format --check app tests typings
```

SQLite 与 HTTP 行为测试、行情边界测试均使用临时独立数据库；测试价格明确标记为 `controlled-test`。正常应用没有注入报价的 HTTP 路由。真实供应商验证另见《行情接入实测》，不能以受控测试冒充实时行情可靠性。

## 尚未交付及限制

- 港美股的可用于真实撮合的事件时间来源尚未验证，生产清单仅观察；不能把受控 USD/HKD 测试当成真实市场验收。
- 未实现自动分红、拆股、应收派息、人工调整流水与每日收益曲线。持仓收益显示参考估值及待核对提示，不能承诺跨公司行动的确定收益。人工暂停不是自动检测，需本人发现后操作。
- 数据缺失时不以零价估值；当前没有持久化的最后可用估值缓存，缺报价会暂不提供总资产汇总。最新汇率用于估值，委托保存的参考汇率仅用于本单兑换。
- 日价格边界仅按已支持证券清单处理，不覆盖新股、ST、停复牌特殊规则和复杂公司行动。五分钟采样会漏掉区间内短暂触价；不模拟排队、部分成交或真实券商交收制度。
- 当前 `exchange-calendars` 境内日历覆盖到 2026-12-31；超出覆盖会拒绝受理，需更新并复验日历，不能自行当作普通工作日。
- SQLite 聚合适用于当前个人单实例，不保证多人高并发。登录、数据归属、HTTPS 和安全 Cookie 的外部部署验收尚未进行；不开放公网。
- 当前轮次初始资金和受控场景已验证；本次时点为境内休市时段，真实“下单后新分钟样本到达并成交”尚待交易时段确认，不以预挂和撤单成功替代。

本地候选版可用于个人验收；港美股真实模拟成交、跨公司行动收益和长期常驻/公网使用仍为 No-Go。

## 最终审查修复与检查结果

最终完整检查为 65 项测试通过，`app` 与 `tests` 全量类型检查为零错误、零警告，Ruff 规范检查通过，30 个文件格式检查通过，OMO 规则审计的 29 个文件无违规。具体结果分别记录于 `.omo/evidence/backend/tests-final.txt`、`types-final.txt`、`lint-final.txt`、`format-final.txt`、`omo-audit.txt`。

独立审查后补齐了三个可复现边界：涨跌停参考必须来自紧邻前一交易日，不能用更早日线代替；ETF 平均单位成本保留小数分位精度，4.189 元买入计费后为 4.1911 元、合计 419.11 元；成功换汇请求在汇率源故障期间重试仍返回原结果，不重复记账。对应 `test_stale_prior_close_rejects_daily_price_bound`、`test_etf_average_cost_preserves_subcent_precision`、`test_conversion_retry_survives_fx_outage` 均通过。

`test_lifespan_fills_persisted_order_without_browser` 启动真实应用生命周期与 `Worker.run`，不发任何 HTTP 请求，使用明确标记的受控市场时钟和完整分钟区间。结束后重新打开 SQLite，验证已落盘委托变为 `filled`、存在两条买入和费用流水以及 100 股持仓。这验证了后台撮合不依赖浏览器；它不替代真实交易时段分钟到达的外部验收。

新增 `.github/workflows/ci.yml` 在 Ubuntu 上使用官方 `actions/checkout@v4`、`astral-sh/setup-uv@v7`、`oven-sh/setup-bun@v2`，工具版本与本地一致为 uv 0.10.12、Python 3.12、Bun 1.4.0。工作流按锁文件安装，运行后端测试、类型、规范、格式以及前端测试和构建；不部署，不读取账户密码。远端运行须在 PM 推送后确认，本报告不将工作流配置完成当成 GitHub 已通过。

## 已交付行为

Python 3.12、FastAPI 和 SQLite 单实例运行。每个新练习轮次以 1,000,000.00 元人民币、零外币和零持仓开始。金额用 Decimal 与分级舍入计算；SQLite 写事务和请求编号唯一约束保证受理、资金、份额、换汇、费用、成交记录一起提交。两个设备不能分别使用同一笔已占用资金。关闭网页不停止后端任务；关闭运行脚本或电脑休眠则不保证后台继续。

支持限价单、带 2% 边界的市价模拟、买卖各 0.05% 费用、整笔成交、当日有效、延迟撤单与到期。订单只使用下单之后的完整、正成交量分钟区间；市场时间、来源、币种、有效交易时段与截止边界均单独判断。不使用估值快照或日线高低点猜测成交；报价失败不会替换成演示数据。撤单等待期间继续占用资金；超出截止后 20 分钟仍无有效确认则以“数据不足，未确认成交”终止，不回填迟到样本。

当前目录扩展为 36 项，包含 16 项境内、12 项美股和 8 项港股。境内和美国已接入完整五分钟来源，美国仅常规时段；港股仍须本人配置并核验实际账户行情，未核验时仅观察。普通股票、ETF 的日价格边界来自逐项规则，不再按单个代码硬编码。不存在盘口时不在买入涨停、卖出跌停边界假定可成交。实际接入范围以《行情接入实测》和运行时目录为准。

A 股及当前境内股票 ETF 按成交所属交易日，到下一交易日开盘才可卖。订单预留既有外币，缺额按本单已保存的参考汇率预留人民币，实际成交才换汇；卖出净款保留外币。同币种余额足够时，汇率故障不阻止相应交易。外币换回人民币、复盘笔记、CSV 导出均有真实接口。

重开练习须先结束全部活动订单。旧轮次不删除；`GET /api/rounds/{id}` 可只读查看现金、订单、笔记及流水，每类最多显示最近 500 条并返回 `truncated`。`GET /api/rounds/{id}/export.csv` 导出该轮完整流水。归档轮次没有写入接口。

## 私有访问与启动

所有账户、行情及交易接口要求登录，启动未配置至少 12 字符的个人密码时不能登录。会话使用 HttpOnly、SameSite=Strict Cookie，最长十二小时；退出或重启后失效。HTTPS 自动加 Secure，本机 HTTP 可保留独立会话。写操作校验来源，登录失败有限速。`PAPER_ALLOWED_HOSTS` 和 `PAPER_ALLOWED_ORIGINS` 精确配置私有入口，不允许主机通配；远程 HTTP 与伪造转发头不能通过。默认只监听 `127.0.0.1:8000`，使用一个 worker，数据库固定为 `backend/data/paper.sqlite3`。公开源码不等于公开账户服务。

首次在项目目录运行：

```bash
cd frontend
bun install --frozen-lockfile
bun run build
cd ..
./scripts/start-local.sh
```

脚本读取已有的私有 `backend/.local-password`，没有文件时在终端隐藏输入并二次确认密码。若本机已有开发验证密码，停止旧服务后执行 `./scripts/start-local.sh --set-password`，设置自己的密码；无需删除数据库。浏览器打开 `http://127.0.0.1:8000`。`Ctrl-C` 停止服务。开发密码、数据库与原始行情样本不得提交公有仓库。

发现分红、拆股、风险警示或交易规则变更后，应先停止服务，以 `PAPER_PAUSED_SYMBOLS=600519.SS,510300.SS ./scripts/start-local.sh` 暂停涉及标的，再核对记录。暂停标的不受理新单，也不处理既有订单成交；仍按截止与超时规则释放占用。这是人工暂停能力，不是自动公司行动识别或自动账本修正。

## 完整个人功能追加验证

本批增加资产日观察、人工股息/拆并股、精确数量快捷键和私有 HTTPS 边界。新增 `snapshots` 与 `adjustments` 表，原 `rounds` 账本不重写。旧数据库升级测试直接删除新增表后重新打开 Store，确认原轮次、现金和持仓完全一致。

北京时间每日第一轮后台任务记录一个实际观察点；正常常驻约在零点，较晚启动则保留真实 `captured_at`。初次行情缺失或过期的当天记录保留为空，不用后来价格覆盖；离线日期不补造点。并发采集只有一个结果，采价期间现金/持仓变化则丢弃混合结果，下轮重试。持仓或外币估值缺失时总资产为空，应收股息列入资产但不能花用。短暂数据库读取错误不会使后台循环退出。

人工股息使用税前每股金额，不模拟个人代扣税；可选择应收，之后确认到账才入现金。拆并股只接受整数结果，总成本完整保留；港股还须保持整手。重复请求返回原结果，另换编号重复登记同一证券、日期、类型仍拒绝。生效日当天或之后已有成交、未结束委托、份额变化和归档轮次均不能调整。采价与公司行动发生竞争时，下单事务再次检查，禁止旧参考价漏入。拆并股后需新报价才能估值；境内新单还须匹配公司行动后的前收盘参考。原始成交和费用不重写。

数量快捷键由 `POST /api/orders/size?percent=25|50|100` 根据同一预留算法计算手续费和换汇后的可买量。HTTP 测试实际验证了查询参数转换和非法比例拒绝，浏览器无需自行进行浮点资金计算。境内日价格范围由目录规则提供，港股使用动态价档且不支持零股成交，美股仅常规时段。美股一美元以上的一美分是本产品保守支持网格，不声称是每只证券当前交易所最小价差。

新增 API 和环境变量见 `.omo/teams/team-16743fbb/artifacts/个人功能接口.md`。日观察和调整记录均可按归档轮次读取，流水导出包含调整编号、依据、份额变化与到账记录。应用改为工厂启动 `app.main:create_app --factory`，导入模块不创建额外数据库或引擎。

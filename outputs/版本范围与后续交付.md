## 仍需本人或外部环境完成的验收

1. **港股数据账号**：安装并登录本人 Futu OpenD，确认 API 协议及免费行情权限；之后由开发验收实际日期、区间标签、不复权数据和交易启用。没有账号不代注册，协议模拟通过不能代替此项。
2. **后台系统权限**：LaunchAgent 已安装，但本次启动被 macOS 的 Python“文稿文件夹”权限提示阻塞；已停止该服务并恢复前台网页。本人允许后才能切换并验证实际常驻与自动恢复。配置检查、plist 安装成功不代表常驻验收通过。
3. **手机入口与真机**：已有 Tailscale 节点可用，Serve/HTTPS 尚需本人在现有账号中启用。之后验证真实代理，再由本人在 iPhone 上登录同一账户和添加主屏幕。手机尺寸浏览器不等同真机。
4. **真实美股盘中**：分钟接口、三市场撮合与自动换汇已有独立证据，但本轮当地时间休市，尚未观察一笔从新下单到后续真实样本的美股成交。

## 交付判断

本地代码候选版可进入个人使用验收；独立审查两项可复现问题均已修复，未留下阻塞代码缺陷。完整三市场、手机与全天可用目标尚不能整体宣布完成：上面列出的真实权限与设备步骤仍缺证据。公有源码可发布，朋友访问及公开账户服务暂不放行。

后台仅保证已登录且保持运行的 Mac；注销、关机、主动休眠会中断处理。它不是云托管，不补造停机期间成交。未来若需要主机关闭仍运行，再单独选择常开托管和费用方案。

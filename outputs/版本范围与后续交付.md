## 已完成常驻与后续接入边界

1. **港股数据账号**：用户没有富途账号，明确决定暂保留观察。OpenD 适配与港股模拟规则已经实现；未来本人登录并确认 API 协议及行情权限后，再核验实际日期、区间标签和不复权数据并启用。
2. **后台常驻**：本轮正式服务重新启动与进程退出后自动恢复通过，原账户与资金保留，最终保留 launchd 管理的单实例。无需终端或 Codex 常开；本轮未重启整台 Mac 验收登录过程，历史初始化阻塞原因不作无证据归因。
3. **手机入口与真机**：用户已完成账号及 HTTPS 启用，开发方实际验证 Serve、证书、登录安全、同一账户与手机尺寸浏览器。Mac 的代理解析影响普通域名，验收仅在测试进程中指定真实 Tailscale 地址；电脑继续使用本机入口。iPhone 自身 DNS、Safari、主屏幕及切网需本人实测，手机仿真不等同真机。
4. **真实美股盘中**：分钟接口、三市场撮合与自动换汇已有独立证据，但本轮当地时间休市，尚未观察一笔从新下单到后续真实样本的美股成交。

## 交付判断

本机个人版可继续使用。本轮真实后台与 HTTPS 开发方验收通过，可以交接 iPhone 实机；真机通过前不将整体手机验收标记为完成。港股实际交易按本人决定暂缓。公有源码可发布，朋友访问及公开账户服务暂不放行。

后台仅保证已登录且保持运行的 Mac；注销、关机、主动休眠会中断处理。它不是云托管，不补造停机期间成交。未来若需要主机关闭仍运行，再单独选择常开托管和费用方案。

## 已完成常驻与后续接入边界

1. **港股数据账号**：用户没有富途账号，明确决定暂保留观察。OpenD 适配与港股模拟规则已经实现；未来本人登录并确认 API 协议及行情权限后，再核验实际日期、区间标签和不复权数据并启用。
2. **后台常驻**：前次实际启动与自动恢复通过；本轮手机更新重启卡在 Python 初始化读取。当前用原目录临时实例恢复本机网页，正式自启待恢复；未重复索要已完成的文稿权限，也未把原因断言为权限问题。
3. **手机入口与真机**：已恢复推进，手机界面、会话恢复和实际 TLS 隔离测试已补齐。Tailscale 管理页尚未登录，需本人确认页面条款及 HTTPS 选项；之后开发方验证真实私有入口，再交接 iPhone 登录与主屏幕安装。手机尺寸浏览器不等同真机。
4. **真实美股盘中**：分钟接口、三市场撮合与自动换汇已有独立证据，但本轮当地时间休市，尚未观察一笔从新下单到后续真实样本的美股成交。

## 交付判断

本机个人版可继续使用。此前本地行为、实际后台与 GitHub CI 已通过；本轮手机增量单独记录于手机验证报告。港股实际交易按本人决定暂缓；手机远程入口仍待账号启用与真实路径验收，不能宣传为已完成。公有源码可发布，朋友访问及公开账户服务暂不放行。

后台仅保证已登录且保持运行的 Mac；注销、关机、主动休眠会中断处理。它不是云托管，不补造停机期间成交。未来若需要主机关闭仍运行，再单独选择常开托管和费用方案。

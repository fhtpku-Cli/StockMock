## 最小接口约定

后端成员先形成最小接口说明，PM 核对后同步前端。金额和百分比保持十进制字符串，未知为 `null`；日期按北京时间自然日，非法日期或起止倒置返回422，归档只读，旧接口保持兼容。

| 接口 | 最小返回与语义 |
| --- | --- |
| `/api/portfolio` | 保留原字段，持仓增加市场、剩余成本、浮动收益率、人民币市值、全账户占比与行情时间；`composition` 返回现金/持仓/应收金额和比例、市场/币种分组、估值时间及缺失原因 |
| `/api/ledger/page` | `items,total,offset,limit,boundary,round_id`；默认50、最大100，先筛选再分页；追加顺序边界固定已加载列表，刷新获取新增记录；旧数组接口保留 |
| `/api/cash-statement` | 每币种初始值、全轮流入流出、计算余额/账本余额/差额、所选日期的期初/期末/流入/流出/净变化与所选类型净变化；汇总按当次完整轮次读取，类型不改变全类型核对 |
| `/api/ledger/export.csv` | 导出当次完整匹配日期/币种/类型的结果；不受当前页限制，原完整资金 CSV 保留，自由文本防公式注入，负金额仍为数值 |
| `/api/snapshots/range` | `range=all/7d/30d/90d/custom`；实际记录、范围、记录/完整/缺失天数、实际首末记录、变化和原因；端点可不完整，不跳过坏端点 |
| `/api/snapshots/export.csv` | 同范围条件，导出已保存字段，缺失金额留空；无条件旧快照数组接口保留 |

归档路由使用 `/api/rounds/{round_id}/` 的同构查询和导出。当前轮翻页期间若轮次变化，前端重载第一页；旧换汇/公司行动无引用时不猜测关联。补充两个后台任务的最小活性字段供部署验收读取，不另建监控服务。

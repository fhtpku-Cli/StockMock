## iPhone 一次性验收

约 5 分钟，不需要 Terminal 或开发者账号。

1. **连接和登录**：打开 iPhone 的 Tailscale，确认连接与 Mac 相同的账号；用 Safari 打开私下提供的完整 HTTPS 地址，保留 `:8443` 端口。使用电脑端同一个 StockMock 密码登录。应直接显示登录页，不出现证书警告。
2. **账户和界面**：核对轮次、资金及委托与电脑一致；依次打开资产、自选、委托和复盘。打开一只可交易标的的交易面板，只填写草稿，检查数字键盘、横竖屏与底部按钮，不必提交委托。
3. **主屏幕入口**：Safari 分享菜单选择“添加到主屏幕”，从新图标重开。首次可能需要单独登录；确认图标、页面和底部安全区域正常。
4. **返回和切网**：切出应用约一分钟再返回；在 Wi-Fi 与蜂窝之间切换后，确认 Tailscale 仍连接，页面恢复、轮次不变、后台处理时间向前推进。已有未提交草稿联网后应重新预览。

完成后只需回复“4 项通过”；失败时说明步骤、页面提示及当时使用 Wi-Fi 还是蜂窝即可，不发送密码。若入口无法打开，先检查手机 Tailscale 的连接状态；不要改成 IP 地址或绕过证书警告。

## 持续运行边界

关闭网页、终端或 Codex 后，当前 LaunchAgent 仍由 macOS 管理。用户登录后自动加载的配置已安装，当前启动与进程退出自动恢复已实测；本轮没有重启整台 Mac 来验收开机过程。服务重启会使旧登录会话失效，重新登录即可，账本保留。

Mac 必须保持开机且该用户已登录；注销、关机和主动休眠会中断处理，不会补造停机期间成交。当前接电设置已不自动休眠，无需修改电源设置。此版本是私人网络访问，不是公开部署，也未开放朋友账户。

此前 Python 初始化读取曾阻塞启动。本轮在当前执行环境中用原项目路径重新启动成功，未修改系统权限、搬迁源码或扩大全盘访问；不能据此断言历史阻塞的唯一原因。

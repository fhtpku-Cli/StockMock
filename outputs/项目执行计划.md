## 已确定的产品

个人使用的多市场模拟投资网页，电脑和手机访问同一账户，后台独立处理挂单。初始 100 万元人民币，市场规划包含A股、港股、美股和ETF；当前真实交易仅开放已核验的A股、美股及相应ETF，港股仅观察，免费行情优先，波段交易优先。成交与撤单允许延迟；买卖各收成交金额 0.05% 的模拟费用，无最低收费；卖出确认后资金可再次买入。

用户选择浅色、清爽的资产看板，突出持仓与收益；没有指定必须支持的个股或 ETF。代表性验证样本不等于完整可交易清单。

## PM 负责确定的首版默认值

- 使用网页/PWA；首页为资产，另有自选、委托、复盘入口。标的详情和买卖面板作为二级页面。
- 一个个人账户，一个活动练习轮次。使用私有访问方式，不开放注册。
- 默认限价单，提供带 2% 保护的市价模拟；只支持当日有效、常规连续交易时段、整笔成交。不做融资、做空、自动止损、盘口排队、盘前盘后和社交排名。
- 按下单后的有效市场时间样本成交；限价边界不突破。撤单以请求时刻为截止，确认前保留占用资金。数据缺失不制造成交。
- 港美股买入优先使用已有同币种现金，缺额在成交时自动换汇；卖出后保留外币，可手动换回人民币。首次实现中汇率和来源必须明确，不用隐藏的固定汇率冒充真实汇率。
- 首版普通交易费用按已确认的 0.05% 执行，不另外添加固定滑点或换汇费；资金交收简化仍保留 A 股与 ETF 的可卖数量差异。
- 交易理由可选，目标价与止损价用于复盘记录，0.2.0起已增加站内到价提示，不自动交易。真实分红、拆股数据不足时明确待核对，提供有记录的个人调整；不显示未经核对的确定收益。
- 优先保证小范围真实行情与完整账本闭环。未验证的标的只观察，示例数据必须与真实数据明确隔离，不能悄悄替代失败的真实行情。

上述可逆的实现与产品细节由 PM 决定，不再逐项询问用户。新增付费、账号开通、公开部署和对外开放在形成具体方案后再处理。用户已进一步授权自行创建公有 GitHub 仓库并进行版本管理，提交范围仅包含源码、测试和中文文档，排除密钥、个人数据库与原始第三方行情。

## 技术与目录

项目已迁入用户创建的 StockMock 项目。开发根目录以该项目文件夹为准；旧目录保留迁移前快照，成员统一在新目录继续开发。迁移保留原有 Git 初始化状态，未覆盖用户提交。

采用 Python 后端、SQLite 持久账本、后台定时处理及 React/TypeScript 自适应前端，保持单体应用。首版本地候选、macOS常驻和Tailscale手机入口均已交付；实际边界见[访问方案](个人访问与常驻方案.md)。SQLite 仅用于当前个人单实例方案，朋友版再按负载评估迁移。

| 范围 | 所有者 | 交付 |
| --- | --- | --- |
| `backend/`，排除下行的行情模块及其测试 | `trade_engine` | 私有访问、持久账本、订单、延迟撤单、换汇、后台任务、HTTP API、行为测试 |
| `backend/app/marketdata.py`、`backend/app/marketdata_models.py`、对应测试及`work/data_probe/` | `market_data` | 行情和汇率真实调用验证、可复用适配模块、准确的时效与失败状态 |
| `frontend/` | `portfolio_ui` | 浅色响应式四页与交易面板、真实 API 联调、PWA 入口、前端构建验证 |
| 根目录说明、`outputs/` 方案和整体验收报告 | 主智能体 PM | 决策、范围、协调、验收及最终交接；子智能体可写各自明确分配的报告 |

所有成员共享工作目录，各自仅编辑拥有的范围，不回滚其他成员变更。接口字段由后端成员先给出最小可用定义并同步前端；这是普通协作说明，不引入额外冻结机制。

后端已使用FastAPI、Pydantic和标准SQLite/Decimal；Python 使用 uv 管理隔离环境。前端使用 React、Vite、TypeScript，以 Bun 管理项目依赖。框架实际版本以安装锁定和运行验证为准。

## 分批交付与验收（首版历史顺序）

下列工作已形成对应交付，不据此重新开工。后续有新证据时按持续清单确定有限范围。

1. 行情真实探测与工程并行启动：三个市场各有股票及 ETF 样本，记录返回价格、市场时间、取得时间、来源、币种、历史能力、错误及网络边界。
2. 完成个人买卖闭环：初始化、查行情、自选、下单、延迟处理、撤单、持仓、资金、复盘和导出。账户数据重启后仍存在。
3. 后端使用真实数据库验证旧报价不成交、限价边界、撤单竞争、重复请求、资金占用、跨币种和可卖数量；前端通过实际浏览器验证电脑及手机尺寸。
4. PM 检查端到端运行与关键异常，再安排独立审查、修复和复验。数据无法接入时给出具体阻塞，不能用演示接口通过验收后声称真实行情已可用。
5. 输出本地运行与验收报告，明确已通过、尚未覆盖和外部待办。常驻托管、外网手机访问与大陆真实网络验证各自独立报告，不用本地成功替代。

# StockMock 0.2.0 前端验证

日期：2026-10-23。状态：三个前端模块已完成真实 API 联调，隔离候选版通过 Chromium、WebKit 和代码检查，可交给 PM 做独立验收与发布。本文不代表正式部署或 iPhone 真机验收已经完成。

## 实现结果

保留资产、自选、委托、复盘四个主入口及现有浅色设计。自选页分开呈现个人自选、已可交易目录与在线搜索；已启用数量按市场、股票/ETF 汇总，筛选结果每批显示 24 项。在线搜索失败时本地自选和目录继续可用，错误状态提供重试，避免把本地结果误认为在线搜索成功。

证券详情支持建立、编辑、结束交易计划，并展示监控状态和站内提示。计划包含方向、理由、原币参考价、北京时间复盘日期及失效条件，支持草稿、进行中、已结束；结束后只读。旧版本编辑收到冲突后需重新载入，重新载入同时更新计划缓存，后续下单可使用最新版本。下单选择计划后带入理由和参考价，仍经过原有预览、资金、时间及委托确认。提交关联计划及其版本，已受理订单展示当时计划快照，不随当前计划修改而改变。

资产页提示默认每批 5 条，证券详情每批 10 条；可加载更多、切换全部提示、确认已读及导出。无有效行情时直接表达暂不能判断是否到价。归档提示只读。

复盘页提供待复盘、已复盘和全部筛选；全部包含尚未到期、没有计划的旧单和未成交撤单。展开后可对照当前计划、各笔委托当时快照、实际成交、费用、原币已实现收益与笔记。部分卖出会明确仍有持仓，收益不跨币种相加，不因一笔卖单自动结束计划。计划需本人显式结束；未成交撤单可记录判断，不当作盈利交易。

归档计划、提示、复盘、订单、笔记和流水保持只读。历史数据每批 25 条从真实分页接口获取，页面没有原先的 500 条查看上限；完整 CSV 使用独立导出接口，不以当前已加载条数截断。旧单缺失的关联信息显示未记录，不推断历史计划。

## 验证中修复的问题

1. 冲突重新载入曾只刷新表单，后续选择计划仍可能读旧缓存；现在重新载入会同步刷新计划查询。
2. ETF 下单表单曾把四位小数计划参考价当成委托价位校验，阻止正常预览；现在参考价允许独立精度，委托限价步长维持原规则。
3. 旧订单详情的定义列表曾含不合适的段落结构，触发严重无障碍诊断；已修正语义结构。
4. WebKit 的弹窗 Tab 焦点可能离开弹窗；共享弹窗现在显式处理正向与反向焦点循环。
5. WebKit 原生下拉框未遵循 `min-height`，实际仅约 22px；已设置明确高度并加入两种引擎每个截图场景的尺寸断言。
6. 另一设备已结束计划时，冲突重新载入会关闭编辑区并返回只读状态，避免保留不可提交的编辑表单。

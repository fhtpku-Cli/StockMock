## 1. 实际走查与证据边界

正式账户只读核对为0个已保存计划、0份正式结论，复盘接口有4条未关联计划的旧委托。因此本轮使用**两个已有历史受控计划**，不是本人真实投资计划，也不代表本人已认可新交互。未为了演示创建或修改计划、成交、笔记或结论。

样本来自0.4.1恢复验收留存的受控账本。检查旧源无非空WAL后，以只读方式复制到独立数据库，使用现行应用和现有静态包，在本机18374端口查看；后台关闭、外部行情不可用，不影响正式8000实例。没有把受控成交当成真实市场验证，也没有修改系统时钟。走查视口为1578×869；本轮没有手机尺寸或真机验收。原始读取证据仅保存在本机忽略目录 `.omo/evidence/e1-review/`，公有文档用A/B代称，不附账户标识、密码、原数据库或私人自由文本。

## 2. 收敛结论：只做关联委托概览

E1要解决的问题是：**写复盘前，看清这个计划关联的每笔委托发生了什么、依据哪一版计划，再选择一笔核对详情。** 当前事实基本齐全，第一步应减少逐笔切换和来回找依据，不再增加看板、收益账本或一套复盘状态。

选定一个前端小模块：在现有复盘详情增加可选择的关联委托概览，并把原有逐笔对照整体移到正式结论之前。信息顺序为：状态/原始提示背景 → 当前计划 → 实际结果 → 关联委托概览及所选委托原有详情/版本对照 → 历次正式结论与保存表单 → 已记录事实 → 普通笔记。

已有事实时间线、版本逐字段对照、正式结论、待补充提醒、导出均保留。快照重复确实存在，但本轮不删除原订单详情里的快照，也不重构共享订单组件；避免为去重影响委托页和旧记录解释。

### 交互与数据口径

| 内容 | 实施定义 |
| --- | --- |
| 概览范围 | 仅使用本次详情API返回的 `detail.orders`，按既有主体和轮次归属；不按证券代码拼入同证券其他计划，不另行取行情 |
| 每笔内容 | 提交时间（北京时间，含年份）、买入/卖出与委托数量、当前已保存状态、下单计划版本；已成交时再显示原始成交价格及币种、市场成交时间（北京时间，含年份）。使用现有金额/价格精度规则，不自行四舍五入到统一两位 |
| 未成交/缺失 | 非成交状态显示“尚未成交”，不显示成交收益或用限价代成交价；已成交但价格/时间缺失显示“未记录”，不能改成“尚未成交”。无快照显示“当时计划未保存”，不得借当前版本补造 |
| 时间与状态 | 提交时间只负责列表排序，不冒充成交时间。`filled_at` 是市场成交时间；系统确认时间保留在现有详情中，非成交终态的确认时间不得标成成交。沿用既有状态名称；活动委托仅表示当前详情读取时的状态 |
| 排序与数量 | 按提交时间升序、相同时间按完整订单ID排序，明确“按提交时间”；显示总笔数。每次显示20条，复用现有“加载更多”方式；不能截掉后续记录，也不改变后端返回完整orders的约定 |
| 选择与对照 | 第一笔默认选中；每行/卡片提供“查看这笔依据”按钮及可访问的选中状态，点击只更换同一区域的 `OrderRecord` 和 `PlanComparison`；移除旧下拉框，避免双份选择状态。保持焦点在选择按钮，所选详情提供清楚标题和语义关联，键盘可逐项操作 |
| 手机布局 | 宽屏紧凑列表，窄屏卡片/字段换行，不要求横向拖动才能看状态或按钮；不增加横向大表。选择按钮可访问名称包含方向、数量、提交时间及短编号，以区分同时间多笔 |
| 0/1笔 | 无委托保留“尚无关联委托，也可以主动记录观察结论”；1笔直接展示其摘要与原有对照，不增加一次必须点击的步骤 |
| 刷新与切换 | 切换计划、轮次或主体时重置已显示数量及选择；同一主体重新获取详情后保留仍存在的选择，若不存在则回到第一笔，空列表清空。选择/加载更多不得卸载结论表单或丢掉未保存草稿；不得触发保存、已读、结束计划或其他业务写入 |
| 归档和旧委托 | 概览适用于归档和无计划旧委托；归档继续只读，不出现写入入口。无计划旧委托保留缺快照说明。当前计划缺失时仍按已有事实显示，不生成“完整版本历史” |

不新增API、数据库字段、后台任务、依赖服务、hash或通用gate。已存在的权限、归属、事务和结论并发保护保持原样。

## 3. 明确不做与不能回答的问题

不做计划独立收益率、平均持有期、自动执行评分、胜率、归因、区间价格图、基准比较、自动总结、全量计划版本历史、公司行动归属、周期调度或导出格式扩展。

原因具体如下：持仓批次没有计划和原买单归属，另一个计划可以卖出既有持仓，关联买卖净份额可能为负；不能凭净份额判断某计划是否清仓。分红/拆股会改变金额或数量，未复权价格变化不能视作经济回报。现有卖单原币净收益并不包含所有分红与换汇影响；缺日线、历史确认时间或计划版本不能补造。这些问题留待有真实使用需求时分别定义，不能顺手塞入E1。

## 6. 复核与决策

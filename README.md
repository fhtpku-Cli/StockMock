# StockMock · 持仓练习

面向个人使用的多市场模拟投资网页，使用 100 万元人民币虚拟本金练习波段交易。支持电脑和手机界面，目标是后台独立处理延迟行情下的委托。

## 已确定规则

此前 iPhone 四项基础接入由用户确认通过；随后实机截图暴露日期筛选布局漏测。`0.1.2` 增加双引擎具体控件边界与交互回归，`0.4.2` 补充日期兼容修正；2026-10-27用户确认Duo复验通过。电脑浏览器证据和本人实机反馈仍分别记录，不把一次通过扩大为所有手机功能的逐项认证。

- 初始资金 100 万元人民币；港美股买入缺额自动换汇。
- 接受行情、成交和撤单回执延迟。只使用下单后对应的有效市场数据判断成交。
- A 股主板、创业板遵守 100 股起及对应涨跌幅；科创板 200 股起、1 股递增，并校验单笔申报上限。境内普通股票 ETF 使用逐项规则；T+1、零股清仓和暂停保护同样适用于新启用证券。
- 买入、卖出各收成交金额 0.05% 的模拟费用，无最低费用；卖出确认后净款可再次买入。
- 新卖出成交保存原币结转成本和扣除买卖费用后的已实现收益，不含分红及汇率变化；旧成交未记录的数据明确显示未知，不补写历史盈亏。
- 计划分为草稿、进行中、已结束；同一轮、同一证券最多一个进行中计划。计划修改不改写委托当时的依据，两台设备的旧版本编辑会提示重新载入。
- 到价提示只表示观察到有效延迟样本满足参考条件，日期按北京时间；行情不可用时不推断触价，不自动下单或撤单。每个计划修订、每种条件只提示一次。
- 复盘保留部分卖出后的持仓与原币收益，计划结束由本人决定；归档计划、提示、复盘与账本只读，支持完整分页和独立 CSV 导出。
- 正式结论追加保存，旧文不覆盖；另一设备改变事实后旧表单会保留草稿并要求刷新，结果未确认时重试原提交不会重复追加。未知历史版本、确认时间或收益不补造。
- 复盘日期筛选指主体最近记录日，命中主体导出全部子记录；普通笔记日期和资金日期分别筛选。状态数量来自完整数据，切换筛选从首批重新读取。
- 仓位占比使用完整账户总资产，筛选不改变分母；缺失汇率或报价不把已知部分重新归一。资金按币种独立核对，类型筛选不改变全类型期初期末，差额仅提示不改账。
- 区间变化只比较不同日期的实际完整首末快照；无效端点不跳过，缺日不补画，不称收盘收益。快照导出沿用历史保存值。
- 清爽浅色资产看板；资产、自选、委托、复盘四个入口。
- 当前只供本人使用，后续再开放给朋友。

## 本地启动

需要 Python 3.12 或更高版本、uv、Bun。依赖限定在项目环境内。前台启动与可选 macOS 用户级后台服务是两种运行方式，同一端口只运行一个实例。

在项目根目录的 Terminal 中执行：

```bash
cd frontend
bun install --frozen-lockfile
bun run build
cd ..
./scripts/start-local.sh
```

首次启动会在终端安全询问个人登录密码，至少 12 字符；输入时不显示。密码保存到仅本人可读的 `backend/.local-password`，不进入 Git。已有本地密码时沿用该文件；也可由运行环境提供 `PAPER_PASSWORD`。

如果接手的是开发团队已验证的本地实例，先停止服务，再运行 `./scripts/start-local.sh --set-password` 设置自己的密码，账户记录会保留。不要将密码文件提交或发给他人。

浏览器打开 [本地持仓练习](http://127.0.0.1:8000)，使用上述密码登录。前台方式按 `Ctrl-C` 停止服务。关闭网页后，服务仍在运行时会继续处理委托；电脑休眠、退出进程或关机期间不会处理。另一台手机需通过配置好的私有 HTTPS 地址访问，本机回环地址不能直接用于手机。

账户数据固定保存在 `backend/data/paper.sqlite3`。服务重启保留数据库，但登录会话失效，需要重新登录。完整备份还需保存私有密码、运行配置、配置引用的外部证券规则文件及对应源码/锁文件；运行中使用 SQLite 在线备份，或正常停服后复制完整数据库目录。备份只留本机私有忽略目录，详细操作和隔离恢复证据见[本机备份与恢复](outputs/本机备份与恢复.md)。

遇到已知停牌或待核对公司行动时，可以通过 `PAPER_PAUSED_SYMBOLS` 暂停这些标的新单及撮合；已有委托保留到撤单或截止处理。设置页可登记税前应收股息、确认到账和整数拆合股，调整有流水、不可重复入账；复杂事件、碎股、港股非整手及不确定权益数量会被拒绝。该人工路径不能代替公司公告自动服务。

macOS 后台方式：完成上述依赖与构建、正常停止前台实例后，在项目根目录执行 `backend/.venv/bin/python scripts/service.py install`。查看状态用 `status`，停止用 `stop`，重新启动用 `start`，卸载用 `uninstall`。全部命令都保留数据库和密码，且不会终止占用端口的其他程序。详细步骤、系统权限及手机设置见[个人访问与常驻方案](outputs/个人访问与常驻方案.md)。

检查运行配置可执行 `backend/.venv/bin/python scripts/run-service.py --check-config`。检查在隔离数据库副本中完成，不初始化或升级正式账户，也不启动后台任务；通过不代表行情或服务已经运行。启动失败在 `backend/data/logs/service.log` 中记录固定安全类别，当前文件加三份历史各约1MB，日志仅本人可读；终端会转达安全诊断。Python解释器缺失或操作系统拒绝启动时，Python日志无法生效，应同时检查 `service.py status` 与系统任务状态。

## 数据与使用边界

估值、分钟成交样本和日频汇率分别保留来源与时间。只用完整落在订单生效至截止闭区间内的有效五分钟区间判断成交，结束恰好等于截止也有效；零成交量、未结束或跨越订单边界的区间、不支持的交易时段不能制造成交。尚未处理的有效历史区间可在后台恢复后用于成交，并记录实际确认时间和延迟原因；新单参考价及计划到价提示仍保留20分钟时效保护。此规则不模拟盘口排队和真实流动性。

公共行情接口可能变化或拒绝请求。当前没有把接口可访问解释为第三方行情再分发许可；本仓库不包含原始行情数据库。公司行动由本人依据公告录入，收益受行情与汇率时点影响。每日资产快照记录北京时间当天首次实际后台观察，遗漏日期不倒填，缺行情时保留曲线缺口。对外开放前必须确认行情许可和用户数据隔离。

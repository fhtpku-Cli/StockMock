# StockMock · 持仓练习

面向个人使用的多市场模拟投资网页，使用 100 万元人民币虚拟本金练习波段交易。支持电脑和手机界面，目标是后台独立处理延迟行情下的委托。

## 当前进度

2026-10-22：个人候选版已通过本地整合验证和独立审查，包含私有登录、资产、自选、委托、复盘、CSV 导出、换汇及练习轮次。65 项后端测试、4 项前端测试、类型检查、代码规范检查和构建通过。尚未正式部署。

当前仅四个 A 股及 ETF 样本开放模拟委托：`600519.SS`、`000001.SZ`、`510300.SS`、`159915.SZ`。`0700.HK`、`2800.HK`、`AAPL`、`SPY` 仅观察。这是接入验证范围，不是完整市场清单。真实市场接入与受控测试分开记录，不把测试行情当作真实成交依据。

## 已确定规则

- 初始资金 100 万元人民币；港美股买入缺额自动换汇。
- 接受行情、成交和撤单回执延迟。只使用下单后对应的有效市场数据判断成交。
- 买入、卖出各收成交金额 0.05% 的模拟费用，无最低费用；卖出确认后净款可再次买入。
- 清爽浅色资产看板；资产、自选、委托、复盘四个入口。
- 当前只供本人使用，后续再开放给朋友。

## 本地启动

需要 Python 3.12 或更高版本、uv、Bun。依赖限定在项目环境内，不安装系统常驻服务。

在项目根目录的 Terminal 中执行：

```bash
cd frontend
bun install --frozen-lockfile
bun run build
cd ..
./scripts/start-local.sh
```

首次启动会在终端安全询问个人登录密码，至少 12 字符；输入时不显示。密码保存到仅本人可读的 `backend/.local-password`，不进入 Git。已有本地密码时沿用该文件；也可由运行环境提供 `PAPER_PASSWORD`。

如果接手的是开发团队已验证的本地实例，先停止服务，再运行 `./scripts/start-local.sh --set-password` 设置自己的密码，账户记录会保留。不要将密码文件提交或发给他人。

浏览器打开 [本地持仓练习](http://127.0.0.1:8000)，使用上述密码登录。按 `Ctrl-C` 停止服务。关闭网页后，服务仍在运行时会继续处理委托；电脑休眠、退出进程或关机期间不会处理。当前本机地址不能直接用于另一台手机，私有 HTTPS 与常驻托管仍待配置。

账户数据固定保存在 `backend/data/paper.sqlite3`。服务重启保留数据库，但登录会话失效，需要重新登录。备份前先正常停止服务，并保存数据库目录。

遇到已知停牌或公司行动时，可以通过 `PAPER_PAUSED_SYMBOLS` 提供逗号分隔的代码，暂停这些标的新单及撮合；已有委托保留到撤单或截止处理。该手动暂停不能代替公司行动数据服务。

## 数据与使用边界

估值、分钟成交样本和日频汇率分别保留来源与时间。只用下单后完整的有效五分钟区间收盘样本判断成交，零成交量、区间重叠、过期数据和不支持的交易时段不能制造成交。此规则不模拟盘口排队和真实流动性。

公共行情接口可能变化或拒绝请求。当前没有把接口可访问解释为第三方行情再分发许可；本仓库不包含原始行情数据库。分红、拆股和公司行动尚未自动处理，收益仅供参考。对外开放前必须重新确认行情许可和用户数据隔离。
